## Blog 페이지 및 게시글

블로그는 마케팅 글이 아니라 RAG, LLM 파인튜닝, 멀티에이전트, 자동화 프로젝트에서 실제로 부딪힌 문제와 실험 결과를 공유하는 기술 콘텐츠입니다.

### 1. Hybrid RAG가 단순 벡터 검색보다 나은 이유: 실전 비교 실험

키워드 검색과 시맨틱 검색을 결합하면 기업 내부 문서 검색 품질을 높일 수 있습니다. 대형 금융사 내규 3,200페이지와 실제 질문 200개로 BM25, Dense Retrieval, Hybrid RAG를 비교했습니다.

- BM25 Top-5 Recall: 61.2%
- Dense Retrieval Top-5 Recall: 72.8%
- Hybrid RAG(RRF) Top-5 Recall: 84.1%

조항 번호·코드명·고유명사는 BM25가 강하고, 개념적 질문은 Dense Retrieval이 강합니다. 실제 업무처럼 다양한 질문이 섞이는 환경에서는 Hybrid RAG를 기본값으로 사용하는 것이 안전합니다. RRF는 각 검색 결과의 순위를 1/(rank+k)로 점수화해 합산하며 k=60이 일반적으로 잘 작동합니다.

### 2. GPT-4o vs Claude 3.5: 실무 관점에서 어떤 모델을 선택해야 하나

법률 문서 분석, Python 코드 생성, 한국어 문서 작성 세 도메인에서 각각 50개 태스크를 비교했습니다. 법률 문서 분석과 긴 문서의 조항 인용은 Claude 3.5 Sonnet이 강했고, Python 코드 생성은 GPT-4o가 빠르고 실용적이었습니다. 한국어 문법 정확도는 비슷하지만 Claude는 격식체, GPT-4o는 자연스럽고 구어적인 문체에 가깝습니다.

### 3. n8n으로 만드는 AI 문서 자동화 워크플로우

Gmail에서 계약서 첨부 이메일 감지 → PDF 텍스트 추출 → GPT-4o 리스크 조항 분석 → Google Sheets 기록 → Slack 알림의 전체 흐름을 n8n으로 구현합니다. 출력은 JSON으로 강제하면 후속 노드 파싱이 편리합니다. 계약서처럼 민감한 문서는 셀프호스팅 n8n과 실행 로그 보존 정책을 검토해야 합니다.

### 4. 은행 내규 챗봇 구축기: 3,200페이지를 RAG로 처리한 6주의 기록

고정 길이 512토큰 청킹은 조항 맥락을 끊어 검색 품질이 낮았습니다. 조·항·호 단위 구조 기반 청킹으로 개선했습니다. OpenAI text-embedding-3-large와 한국어 특화 bge-m3를 비교했고, 한국어 법률 문서에서는 bge-m3가 10%p 이상 높은 검색 성능을 보였습니다.

### 5. LoRA 파인튜닝 실전 가이드

LoRA는 전체 모델 파라미터 대신 저랭크 행렬만 학습해 메모리와 연산량을 줄입니다. Llama 3 8B, A100 80GB, Hugging Face PEFT·TRL, QLoRA 4비트 양자화를 사용한 사례를 소개합니다. 법률 Q&A 5,000쌍을 만들고 초기 1,000개 학습 후 오답 분석을 통해 나머지 데이터를 보강했습니다.

### 6. RAG 시스템 평가하기: RAGAS 지표

- Faithfulness: 생성 답변이 검색 컨텍스트에 얼마나 충실한지 측정
- Answer Relevancy: 답변이 질문과 얼마나 관련 있는지 측정
- Context Precision: 검색 문서 중 실제 답변에 사용된 비율 측정
- Context Recall: 정답 도출에 필요한 문서가 검색됐는지 측정

금융·법률·의료처럼 위험도가 높은 도메인은 Faithfulness를 우선합니다. 일반 Q&A는 Answer Relevancy와 Context Recall의 균형을 보고, 검색 최적화는 Context Precision을 중점적으로 봅니다.

### 7. LangGraph로 Multi-Agent 시스템 설계하기

- Supervisor: 중앙 관리자 에이전트가 작업을 분배하고 결과를 취합
- Parallel: 독립적인 에이전트를 동시에 실행해 속도를 높임
- Sequential: 이전 단계 결과를 다음 단계 입력으로 전달

복잡한 조율은 Supervisor, 독립 작업은 Parallel, 단계적 변환은 Sequential이 적합합니다. 실제 프로젝트에서는 세 패턴을 조합합니다.
